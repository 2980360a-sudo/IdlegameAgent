# Melvor Idle 赚钱（Money Making）指南

> 来源：官方 Wiki「Money Making」策略表

## 基础游戏（无 DLC）赚钱法（按收益从高到低）

| 方法 | 收益/小时 | 需求 |
|------|----------|------|
| 弓匠龙矛 + 生活魔法 | ~18m | 伐木90 采矿95 锻造93 弓匠92 符文80 魔法95 |
| 基础战斗 | ~18m | 战斗99 祈祷99 魔法/攻击85 |
| 基础灵巧 | 1.1m~6.3m | 灵巧99 星象70 扒窃60 草药62 农务60 采矿60 屠杀60 伐木80 生火80 三战斗95 |
| 钓鱼鲸鱼 | 310k~3m | 钓鱼95 |
| 采矿 + 宝石手套 | 306k~2m | 采矿50 |

## DLC 高收益法（TotH/AoD/ItA）

- **扒窃吸血鬼**（TotH）：15.4m~105m/h，扒窃115 + 草药45 + 星象70。
- **弓匠陨石弩箭**（TotH）：~80m/h，锻造110 + 采矿112 + 弓匠108。
- **高等级灵巧**（TotH）：16.8m~63m/h，灵巧120 + 制造/弓匠/锻造115。
- **采矿纯水晶**（AoD+TotH）：4m~39.5m/h，采矿85 + 草药53。
- **屠杀币农场**（AoD+TotH）：148m~480m/h，需高等级战斗/屠杀/召唤/符文。
- **终局 ItA**：110b~225b/h（后期毕业内容）。

## 赚钱决策要点（Agent 遵循）

1. **金币紧张时**优先用当前技能等级对应的最高收益法（对照上表）。
2. **早期**（钓鱼95 前）：采矿+宝石手套（采矿50 起）→ 钓鱼鲸鱼（钓鱼95）→ 龙矛（多技能）。
3. **有 TotH**：优先扒窃吸血鬼（扒窃115）或陨石弩箭（锻造110）。
4. **宝石手套机制**：设宝石出率为 100%，故其它加宝石几率的效果不生效，靠卖宝石赚金币。
5. **龙矛**是基础游戏经典赚钱法（用伐木攒的红木做矛杆 + 生活魔法超高温炼锭）。
